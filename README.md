## 概述 / Overview

**了空居士**（俗名蔡衍颛）是当代实修型禅师，长期义务通过网络为大众答疑解惑，其教导涵盖《道德经》《金刚经》《心经》等经典的实修解读，以及修行方法、处世智慧、身心健康等方方面面。

本项目参照 **Andrej Karpathy 的 [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 思路**，融合**芒格心智模型"五层结构"方法**，构建了一个由 LLM 辅助维护的结构化智慧知识库。

**核心理念**：

- 🧠 **蒸馏，而非摘录** — 从原文提炼"模型原子"（指导判断与行动的原则性语句），而非简单复制章节
- 🏗 **持久化，而非临时检索** — 每次积累都沉淀为可复用的结构化知识
- 🤖 **LLM 做"苦力"** — 负责提炼、聚类、更新、交叉引用，人类负责方向指引与深度验证
- 🌱 **自生长** — 会不断演化的知识网络，而非静态文档集合

```
│   ├── 10-核心模型/        ← 第一层：7个核心心智模型

│   ├── 40-原话金句/        ← 第四层：金句库（按经典+模型索引）
│   └── 50-概念资料/        ← 第五层：术语词典 + 资料索引
│
├── 03-Output/             ← 最终产物层（用户消费）
│   ├── 学习指南.md
│   ├── 核心摘要.md
│   └── 专题报告/
│

```

### 三层数据流

```
Raw Sources（不可变原始数据）
    ↓ 双重提取：分类整理 + 模型原子提炼
Wiki（LLM 维护的结构化知识）
    ↓ 五层导航
Output（用户消费的最终产物）
```

## 方法论 / Methodology

本项目融合了两套方法论：

### Karpathy LLM Wiki

由 Andrej Karpathy 提出的知识管理范式：将 LLM 作为 Wiki 的**永久维护者**，而非瞬时检索工具。LLM 反复读取原始资料、更新 Wiki 页面、维护交叉引用，实现**持久化合成**。

### 模型原子 → 核心心智模型 → 五层结构

参照芒格心智模型项目的组织方式：
1. **模型原子**：从原文中提炼"能指导判断与行动的原则性语句"
2. **核心心智模型**：将原子聚类为 7 个核心模型
3. **五层导航结构**：模型层 → 专题层 → 路径层 → 原话层 → 概念层

> **"蒸馏"比"摘录"更重要** — 每个模型原子都是原文智慧的精炼表达，而非简单复制。

## 维护方式 / Maintenance

### LLM 负责

- 扫描新文章，识别并提炼模型原子
- 将原子归入对应核心模型
- 更新 Wiki 页面结构和内容
- 维护交叉引用和索引
- 执行健康检查（lint）

### 人类负责

- 制定研究方向（哪些模型最重要？）
- 验证提炼精度（原子是否准确？）
- 指导应用整合（如何组合模型解决实际问题？）
