# 认知路径

> 系统学习路径：按次第建立对七大核心心智模型的完整理解。
> 适合希望系统建立智慧体系的学习者。

---

## 路径总览

```
对境不住（心法基础）
    ↓
对法不执（心法深化）
    ↓
自然务实（方法论）
    ↓
圆融中和（处世智慧）
    ↓
历境炼心（实践功夫）
    ↓
天人合一（世界观）
    ↓
性命双修（圆满整合）
```

---

## 第一阶段：对境不住 | 不被现象迷惑

**核心问题**：为什么我总是被外界带着跑？

**目标**：学会觉察——知道自己在做什么、想什么，不被现象牵着走。

**学习方法**：

| 步骤 | 内容 | 参考资料 |
|------|------|---------|
| 1.1 | 理解什么是"相"——一切外在现象都是相 | [对境不住模型](/10-核心模型/model-对境不住) |
| 1.2 | 学习区分"事实"和"我的反应" | 原子：离相即客观、知见无见 |
| 1.3 | 实践"保持平静的窍诀" | 原子：保持平静的窍诀 |
| 1.4 | 理解"过去心不可得"的三层含义 | 原子：三心不可得 |

**实战应用**：
- [如何处理情绪](/20-专题研究/topic-情绪) — 觉察情绪的第一步
- [如何面对焦虑](/20-专题研究/topic-焦虑) — 焦虑是对未来"相"的执着

**检验标准**：当你被批评时，第一反应不是反驳，而是先听完。

> **关键金句**："不平静时问自己：'我为什么要不平静？这样正确吗？'"

## 第二阶段：对法不执 | 放下一切执着

**核心问题**：我知道不该被现象带跑，但为什么还是放不下？

**目标**：从"不被外部带跑"深化到"不执着于任何东西，包括方法本身"。

**学习方法**：

| 步骤 | 内容 | 参考资料 |
|------|------|---------|
| 2.1 | 理解"法尚应舍"——连方法都要放下 | [对法不执模型](/10-核心模型/model-对法不执) |
| 2.2 | 学习不执功德相——做好事不留念 | 原子：不执功德相 |
| 2.3 | 理解"即得不等于得后"——当下即是 | 原子：即得不等于得后 |
| 2.4 | 通达无我法——一切自然流露 | 原子：通达无我法 |

**实战应用**：
- [如何看待财富与布施](/20-专题研究/topic-财富与布施) — 放下对功德的执着
- [如何面对忍辱与原谅](/20-专题研究/topic-忍辱与原谅) — 放下"被侮辱"的标签

**检验标准**：你做了一件好事之后，心里有没有"我做了好事"的感觉？

> **关键金句**："雷锋帮完人就走了，不等着对方说谢谢。"

## 第三阶段：自然务实 | 抓核心，做实事

**核心问题**：道理懂了，但是怎么落实到行动上？

**目标**：把道理变成行动——不绕弯子，抓核心，做该做的事。

**学习方法**：

| 步骤 | 内容 | 参考资料 |
|------|------|---------|
| 3.1 | 理解"无为"——不是不做，是不乱做 | [自然务实模型](/10-核心模型/model-自然务实) |
| 3.2 | 学习"因上精进，果上随缘" | 原子：因上精进果上随缘 |
| 3.3 | 理解"经验不能照搬" | 原子：经验不能照搬 |
| 3.4 | 实践"信解行证"的四步法 | 原子：信解行证 |

**实战应用**：
- [如何做出选择](/20-专题研究/topic-选择) — 务实决策
- [在工作中修行](/20-专题研究/topic-工作修行) — 工作即修行

**检验标准**：遇到问题时，你更多是在想"怎么办"还是"为什么又是我"？

> **关键金句**："做就是了。行动胜过千言万语。"

**目标**：找到中道——在每一件事情上做到恰到好处。

| 4.2 | 学习整体观——看待问题的全局视角 | 原子：整体观定善恶 |
| 4.3 | 理解"智慧布施"——不给、不贪、不吝 | 原子：智慧布施 |
| 4.4 | 实践"无断无灭"——不落两边 | 原子：无断无灭 |

**实战应用**：

**检验标准**：在争论中，你能不能同时看到对方立场中的合理之处？

## 学习建议

### 速度建议
- **第一阶段**：1-2周，打好觉察基础
- **第二阶段**：2-3周，反复体会"放下"
- **第三阶段**：1-2周，重点在行动
- **第四阶段**：2-3周，在生活中找"度"
- **第五阶段**：长期，每一个烦恼都是一次考试
- **第六阶段**：1-2周，反复体悟宇宙观
- **第七阶段**：长期，一日修行一日功

> 不必按部就班地"学完"——遇到哪些问题，就去对应的阶段找答案。
