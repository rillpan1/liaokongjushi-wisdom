# 道教学人入口

> 如果你练过丹道、气功、站桩，或读过道德经，从这里开始了空居士的体系。

---

## 你可能已经在修

- **丹道/周天** → 了空居士走的是**顿超法门**（天元丹法），不搞采气练气，一个动作完成所有
- **气功/站桩** → 他的方法更简单——"轻轻意守手指脚趾"，不守丹田，自然呼吸
- **道德经** → 他对"无为""守中""道法自然"有非常务实的解读

---

## 推荐学习路径

### 第一步：先了解"顿超法门"

如果你之前学的是渐修丹法（筑基→小周天→大周天→…），先理解他为什么走另一条路：

1. **不采气、不练气、不行气** —— "你们跟我学的，就不用搞那些采气了"
2. **直接从中丹田入手** —— "神守黄房"（轻轻返观整个体腔）
3. **师力加持** —— "我师父当年是以师力加持的，刹那间就通大周天了"

读：[性命双修模型](/10-核心模型/model-性命双修)（重点关注"顿法·渐法之辨"节）
原文入口：[中论丹道-师力加持](/60-原文段落/中论丹道-师力加持)、[五篇灵文-温养章全段](/60-原文段落/五篇灵文-温养章全段)

### 第二步：理解"宇宙统一场"

他用现代物理学的"场"重新定义了"道"：
- 道 = 宇宙统一场 = 万物最底层的统一能量场
- 修行 = "不是练出来的，是融进去的"
- 聚气 = "有为法，是我执，跟大自然能量场不沟通"

读：[天人合一模型](/10-核心模型/model-天人合一)
原文入口：[论坛语录-宇宙统一场](/60-原文段落/论坛语录-宇宙统一场)、[虚无中的共振-能量共振](/60-原文段落/虚无中的共振-能量共振)

### 第三步：实修方法

- 静坐方法：[五篇灵文-温养章全段](/60-原文段落/五篇灵文-温养章全段) — 神守黄房，似守非守
- 念佛替代意守：[念佛-显现极乐](/60-原文段落/念佛-显现极乐) — 心念耳闻+显现极乐
- 日常收功：[修行即生活-收功](/60-原文段落/修行即生活-收功)
- 意守手脚：[修行即生活-意守手指脚趾](/60-原文段落/修行即生活-意守手指脚趾)

### 第四步：了解心法

丹道重"命功"（身体修炼），了空居士强调"性命双修"——心和身要一起转化：
- [对境不住](/10-核心模型/model-对境不住) — 静坐中杂念来了怎么办
- [自然务实](/10-核心模型/model-自然务实) — 修行化繁为简

---

## 你可能发现的不同

| 传统丹道/气功常见说法 | 了空居士的说法 |
|---------------------|-------------|
| 意守下丹田 | 轻轻返观中丹田（膻中一带覆盖整个体腔） |
| 调息（顺/逆腹式呼吸） | 自然呼吸就好 |
| 采气、练气、行气 | 不采自足，"但安神息，不运火而火自运" |
| 文火/武火有讲究 | "似守非守"就是全部火候 |
| 先修命后修性 | 性功命功同时完成——轻轻返观一个动作，心和身一起转 |
| 百日筑基后才能通周天 | 师力加持下可能"刹那间通大周天" |
