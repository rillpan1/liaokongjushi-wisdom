## 认知路径

**路径**：7大核心模型逐阶深入

```
对境不住 → 对法不执 → 自然务实 → 圆融中和
                                        ↓
历境炼心 → 天人合一 → 性命双修
```

**特点**：
- 按模型的逻辑次第排列
- 每阶段有明确的学习目标和检验标准
- 配合专题和实修建议

## 新手入门

**路径**：七天入门计划

```
Day1 认识 → Day2 心法 → Day3 静坐
       ↓
Day4 情绪 → Day5 深入 → Day6 习惯
       ↓
Day7 回顾与展望
```

**特点**：
- 每天20-30分钟即可
- 从零开始，不需要任何基础
- 覆盖了从认知到实践的完整入门
