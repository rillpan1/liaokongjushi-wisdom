## 认知路径

**路径**：先明理，再修心，后行事。

```
天人合一（世界观──先明理）
    ↓
对境不住（心法：对外不动心）
    ↓
对法不执（心法：对内不执方法）
    ↓
自然务实（方法论：抓核心做实事）
    ↓
圆融中和（处世智慧：不走极端）
    ↓
历境炼心（实践：在事上磨）
    ↓
性命双修（圆满：身心一体）
```

**特点**：
- 按模型的正确次第排列——天人合一定在第一阶段（一切心法的世界观基础）
- 每阶段4个步骤，每步都有**原文段落链接**（可直接读到空居士原话）
- 每阶段有**常见卡点+突破方法**
- 检验标准可操作，不是空泛的"你懂了没"
- 整体观贯穿全程

> **为什么天人合一放在第一步？** 了空居士说"先明理，再修行"。天人合一的因果观（因果不空）和一体观（万物一体）是所有心法的坐标系——不知道"为什么"，修"怎么做"很容易走偏。

## 问题路径

**路径**：以具体问题为入口，层层深入模型。

```
火线入口（12个专题，每个配核心原文片段）
        ↓
深度路径（5条问题→模型链，每步有操作+原文出处）
        ↓
全景图（专题-模型-原文三栏对照表）
```

**特点**：
- 火线入口表每行配**核心原文片段**——直接看原话再判断
- 5条深度路径各扩展为6步操作表，每步有**做什么+参考资料+原文出处**
- 全景图为专题-模型-原文对照表（清晰可查）
- 新增"如果专题没解决你的问题"四个备选方案
- 整体观提示置于路径总览

## 新手入门

**路径**：七天入门计划，每天有原文可读。

```
Day1 认识 → Day2 心法 → Day3 静坐
       ↓
Day4 情绪 → Day5 深入 → Day6 习惯
       ↓
Day7 回顾与展望（三条后续方向+原文入口）
```

**特点**：
- 每天的方法/实践都配**原文段落链接**——新人直接读到原话，不依赖二手解读
- Day2 模型学习更新为最新结构（引用具体原子而非"前5个"）

## 三路径关系图

```
谁在看？
    ↓
  初学者？  →  新手入门路径（七天计划）→ 7天后选认知路径或问题路径
    ↓
  有具体问题？ →  问题路径（按图索骥）→ 问题解决后可选认知路径
    ↓
  系统学习者？ →  认知路径（逐阶深入）→ 遇到具体问题回查问题路径
    ↓
              ← 三条路径互补，殊途同归 ←
```

## 如何组合使用三条路径

1. **新手入门（1周）→ 认知路径（系统学）**：最推荐的路径。先用7天建立基本认知，再按认知路径逐阶段深入。
2. **问题路径 + 认知路径（并行）**：日常遇到问题走问题路径，空闲时间走认知路径——两条路互相补充。
3. **只走问题路径**：适合不想系统学、只想解决具体问题的人。每个问题解决后自然接触到背后的模型。
