# 佛教学人入口

> 如果你学过净土、禅宗、或读过佛经，从这里开始了空居士的体系。

---

## 你可能已经在修

- **净土念佛** → 了空居士的念佛方法是"心念耳闻+显现极乐"，不是计数量。参见 [如何开始实修](/20-专题研究/topic-入门实修) 第二节
- **禅宗参究** → 了空居士说"应无所住而生其心"是总纲。不是坐着参，是在生活中历境炼心
- **读经学教** → 了空居士讲经"直指人心"——不讲学术考证，直接告诉你核心是什么、怎么用

---

## 推荐学习路径

### 第一步：先看心法

了空居士把佛教修行的核心提炼为两个心法：

1. **对境不住**（不被现象迷惑）
   - 对应你熟悉的："应无所住而生其心""凡所有相皆是虚妄"
   - 读：[对境不住模型](/10-核心模型/model-对境不住)
   - 原文入口：[金刚经10分-应无所住生心](/60-原文段落/金刚经10分-应无所住生心)

2. **对法不执**（连佛法也要放下）
   - 对应你熟悉的："法尚应舍，何况非法"
   - 读：[对法不执模型](/10-核心模型/model-对法不执)
   - 原文入口：[金刚经6分-法尚应舍](/60-原文段落/金刚经6分-法尚应舍)

### 第二步：再看世界观

了解他如何用"宇宙统一场"翻译传统佛学概念：
- 佛性 = 法性 = 实相 = 宇宙统一场
- 读：[天人合一模型](/10-核心模型/model-天人合一)
- 原文入口：[论坛语录-宇宙统一场](/60-原文段落/论坛语录-宇宙统一场)

### 第三步：方法和实践

- [自然务实](/10-核心模型/model-自然务实) — 抓核心，不搞繁复
- [圆融中和](/10-核心模型/model-圆融中和) — 中道，不走极端
- [历境炼心](/10-核心模型/model-历境炼心) — 烦恼即菩提，生活即道场

### 第四步：功法（可选）

如果你对"禅定"的实操感兴趣：
- [性命双修](/10-核心模型/model-性命双修) — 他融合丹道的"性命双修"体系
- 读：[五篇灵文-温养章全段](/60-原文段落/五篇灵文-温养章全段)

## 你可能发现的不同

| 传统佛教常见说法 | 了空居士的说法 |
|----------------|-------------|
| 要断烦恼 | 烦恼即菩提——烦恼是觉悟的机会 |
| 要入定、不起念 | 不怕念起只怕觉迟——有念头正常，觉察到就是功夫 |
| 修行要远离尘世 | 家庭是道场，工作单位是道场 |
| 要持戒才能修行 | 不守五戒念佛也有用——因果分条算 |
| 要证果位 | 即得不等于得后——当下即是，不觉得证了什么才是真证得 |
