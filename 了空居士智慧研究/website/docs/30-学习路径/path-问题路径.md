# 问题路径

> 以问题为导向的学习路径：你遇到什么问题，就从对应的专题入手。
> 适用人群：带着具体问题来学习的人。

---

## 路径总览

```
你有具体问题吗？
    ↓
选择对应专题
    ↓
理解背后的核心模型
    ↓
实践方法
    ↓
深入下一个相关问题
```

## 深度路径：从问题到模型

每个专题背后都有核心模型。当你解决了表面的问题后，建议进一步学习背后的模型。

### 路径A：情绪型问题

```
情绪/焦虑 ← 对境不住（觉察→不被带跑）
                        ↓
                  对法不执（放下执着）
                        ↓
                  历境炼心（转化烦恼）
```

**推荐阅读顺序**：
1. [如何面对焦虑](/20-专题研究/topic-焦虑)
2. [如何处理情绪](/20-专题研究/topic-情绪)
3. [对境不住模型](/10-核心模型/model-对境不住) — 觉察是第一步
4. [对法不执模型](/10-核心模型/model-对法不执) — 放下的智慧
5. [如何开始实修](/20-专题研究/topic-入门实修) — 从静坐中练习

## 如何选择自己的路径

1. **看看你现在最困扰的是什么** → 去火线入口找对应专题
2. **读完专题后，去学背后的模型** → 每个专题末尾的"推荐模型"
3. **沿路径深入下一个相关问题** → 上面有5条深度路径可选
4. **最后读理论** → [核心摘要](/核心摘要)和[学习指南](/学习指南)

> 了空居士说："学东西不要追求'学完'，追求'用上一条就赚一条'。"
