# 问题路径

> 以问题为导向的学习路径：你遇到什么问题，就从对应的专题入手。
> 适用人群：带着具体问题来学习的人。

---

## 路径总览

```
你有具体问题吗？
    ↓
选择对应专题（火线入口）
    ↓
读原文片段，听原话怎么说的
    ↓
理解背后的核心模型
    ↓
实践方法（每步都有原文依据）
    ↓
深入下一个相关问题
```

> **整体观提示**：不管从哪个入口进来，先用整体观做一次"三层缩放"——跨时间看因果链、跨立场看各方利益、跨层次看本质。这让你不会只见树木不见森林。详见 [整体观元方法](/meta-整体观)。

## 深度路径：从问题到模型

每个专题背后都有核心模型。当你解决了表面的问题后，建议进一步学习背后的模型。

### 路径A：情绪型问题

```
情绪/焦虑 ← 对境不住（觉察→不被带跑）
                        ↓
                  对法不执（连"要平静"的执着也放下）
                        ↓
                  历境炼心（把每一次情绪波动变成觉悟机会）
```

## 如果专题没解决你的问题

1. **先看原文** → 每个专题都有"核心原文"列——读完原文片段再判断
2. **试一个模型的完整操作法** → 每个模型页面都有"操作方法"章节，选一个试
3. **换个入口** → 如果路径A没解决情绪问题，试试路径C（行动）——有时情绪的根源是不知道怎么行动
4. **用整体观三层缩放** → 跨时间（这件事十年后还重要吗？）、跨立场（对方怎么看？）、跨层次（从更高层面看，什么最重要？）
