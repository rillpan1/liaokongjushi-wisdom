# 顽空

## 定义

顽空是修行误区：把"空"误解为什么都没有、什么都不做、什么都不想，陷入死寂和消极的状态。

## 了空士原话

> "最清净的人就是死人。第二清净的人就是老人痴呆症。"

> "有些人以为打坐就是要'入静'，拼命压念头，越压越烦躁。"

> "万法皆空，因果不空——万事万物都不是永恒的，但是因果相续的规律是永恒的。"

## 顽空的表现

- 以为修行就是"什么都不想" → 变成发呆
- 以为"空"就是没有感觉 → 变成麻木
- 以为"放下"就是什么都不管 → 变成不负责任
- 以为"无我"就是没有自我 → 变成自卑

## 如何避免

了空士说：**空不是没有，是不永恒。** 照见五蕴皆空，是知道一切都在变化，不是否定一切存在。
