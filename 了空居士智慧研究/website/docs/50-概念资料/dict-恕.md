# 恕

> 传统：儒家（"己所不欲，勿施于人"）| 佛家对应：慈悲 | 道家对应：不争

## 了空居士的定义

"恕"就是**推己及人**——你不想被怎样对待，就不要那样对待别人。这是了空居士判断是非的**底线标准**。

他说：日本人侵华，他们说是在"帮助落后民族"，但"己所不欲，勿施于人"——你不想被侵略，就别侵略别人。这个底线一拉，是非立判。恕是整体观的"底线版"——当你无法做完整的整体分析时，先用恕来检验：你希望别人这样对你吗？

## 常见误解

| 误解 | 正解 |
|------|------|
| 恕就是原谅一切 | 恕首先是"不做伤害别人的事"，其次才是原谅 |
| 恕就是软弱 | 恕是底线的智慧——判断是非最快的检验标准 |
