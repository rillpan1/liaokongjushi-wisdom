# 家庭道场

> 传统：儒家（齐家）| 佛家对应：在家修行 | 道家对应：和光同尘

## 了空居士的定义

"家庭道场"就是了空居士对**家庭即修行现场**的核心观点。家庭不是修行的障碍，而是最好的修行场所——因为家人是你最亲近的人，也是最容易触发你情绪的人。在家里磨出来的功夫，是真的功夫。

关键操作：在家庭关系中保持**柔软**——"石头和石头之间不填上水泥浆，那个石头永远是摆不平的。" 家庭中需要有一个人先软下来，不是软弱，是智慧。了空居士特别指出男人的责任——在家庭关系中主动表达温情、主动化解矛盾。

## 原话出处

> "家庭是道场，工作单位是道场，社会是道场。" — [金刚经1分-修行在生活中](/60-原文段落/金刚经1分-修行在生活中)

> "家庭里面最重要还是我们男人。如果妻子不开心，你拉拉手摇摇肩膀都可以。两个人都是硬邦邦的，永远摆不平的。" — 修行入世（20090112b）

## 修行实践

在家里，当情绪起来时，先停三秒，深呼吸——这就是在家里的"静坐"。主动表达温情，不把家人的好视为理所当然。
