# 守中

> 传统：道家 | 佛家对应：中道 | 儒家对应：中庸

## 了空居士的定义

"守中"就是**看准最佳时机，以最客观的方式去做**。不是停在中间不动，而是不走极端、不盲动、不妄动。了空居士比喻："就像开车，要不断微调方向才能保持在车道中间。"

守中不是折中主义——"中"是最客观的判断点，是根据整体观找到的最佳行动方案。

## 原话出处

> "多言数穷，不如守中。'中'就是最客观，看准最佳时机。" — [道德经5章-多言数穷不如守中](/60-原文段落/道德经5章-多言数穷不如守中)

> "守中不是停在中间不动，是不走极端。就像开车，要不断微调方向。"

## 常见误解

| 误解 | 正解 |
|------|------|
| 守中就是"中立"、谁也不得罪 | 守中是找到客观上最佳的方案，不是和稀泥 |
| 守中就是不行动 | 守中是不盲动不妄动，该动就动，看准最佳时机 |
