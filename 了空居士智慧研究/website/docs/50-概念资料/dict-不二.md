# 不二

## 定义

不二是大乘佛法的核心思想——超越二元对立（善恶、对错、美丑、生死等），看到事物的统一性。了空居士的理解非常实用：不是否定二元，是不被二元所束缚。

## 了空居士原话

> "色不异空，空不异色——物质和空不是两回事，是不二的。"

> "不生不灭、不垢不净、不增不减——不是中间状态，而是超越了这些对立的概念。"

> "不二不是说不要分好坏善恶，是说不要被好坏善恶这些概念绑住。该善的善，该恶的恶，心里没有挂碍。"

## 了空居士的独特诠释

了空居士非常强调：**不二不是什么都不分**。修行不是变成"是非不分"的人，而是**做正确的事但不被"做正确的事"这个念头绑住**。这是他对"不二"最务实的解读。

## 日常理解

| 二元对立 | 不二视角 |
|---------|---------|
| 成功/失败 | 都是一种经历，都是成长 |
| 好人/坏人 | 每个人都有善和恶的种子 |
| 快乐/痛苦 | 都是生灭的，不永恒 |
| 修行/世俗 | 家庭、工作都是道场 |

- 遇到对立的事物，试着找出它们共同的一面
- 不急着站队，先看看整体
- 做正确的事，但做完就放下
