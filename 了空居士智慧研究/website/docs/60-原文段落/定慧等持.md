# 定慧等持

> 来源：[20090120了空居士谈修心与定慧等持](/01-Raw-Sources/20090120了空居士谈修心与定慧等持)
> 切分日期：2026-05-06

---

**原文一（定慧等持的解释）：**

你在这个空里，你身体很虚无的时候，你还提起念头，念佛念佛，这个时候你的身心又非常虚无，你又还会念佛，念佛是慧，身体虚无这是定。这就是定慧等持。这才是通到最圆满境界的法门。

**原文二（寂照不二与定慧等持）：**

其实一心念佛本来就具足定慧。一心是定，念念分明是慧。所谓"定慧等持"不是先定后慧，也不是先慧后定，而是定中有慧、慧中有定，两者同时具足。就像我们念佛的时候，心不散乱是定，佛号清清楚楚是慧，定和慧不是两件事，而是一件事的两个面。

你们很多人修行啊，修到一定的禅定境界之后，就进到那个空寂虚无的境界，他们老是以为那个无分别心是善恶不分别。不是，善恶从事相上来说是绝对不同的，但是它的本性是相同的，本性是什么？性空。了无自性嘛。所以叫做缘生性空，从事相上来说、从形象上来说是不一样的，从本性上来说都是空寂的。

你就就是不要定哪个对错，不要生起一种哎呀你们怎么争吵了。你这个平静的心就是无分别。不生起烦恼，你认真听一言一语听得清清楚楚，这就是慧，这就是照。我们很多词有寂照啦，定慧啦，其实它都不用场合说明的是同一个道理，寂就是定。照就是慧。心平气和就是寂，认真听我们说历历分明就是照。寂照不二。所以最好境界就是一点不烦，很自然听，听得对的当参考，听得错的你忏悔。这个时候你就是无分别。
