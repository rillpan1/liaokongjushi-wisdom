# 答疑2014-顺逆皆修与冤亲平等

> 来源：[08_答疑专辑2014_练功（上）](/01-Raw-Sources/08_答疑专辑2014_练功（上）)
> 切分日期：2026-05-06

---

**师父答：**……我们修炼有两个层次，一个是在顺境里边修炼，就要在风和日丽环境优美的地方修炼，这其实是基础功。功夫高深的人反而要反过来，要在恶劣的环境里边练，练到你的心如如不动了，你的功夫才是真的。当然千万不要到一些危险的地方去练，那悬崖边啊掉下去就没命了，不必要的，反正就是说有这个相反，就像藏密所说的"冤亲平等"的修炼，我们初级阶段要观想我们的亲人我们的恩人在我们的身边，我们一心念佛和他们一起修行，调出感恩的心。功夫更深了你要想象和你的仇人在一起修炼，从恨他修到原谅他甚至是同情他，这叫做冤亲平等。谢谢大家！
