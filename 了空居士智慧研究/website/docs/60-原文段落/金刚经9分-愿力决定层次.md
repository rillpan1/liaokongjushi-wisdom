# 金刚经9分-愿力决定层次

**了空居士**：我告诉你，三昧是一个圆满的境界，三昧据说也是印度语，翻译成中国话说就是正受。正受其实也就是大定，那大定大到多大？到处都是定，繁兴永住那伽定。大定，就是没有入，也没有出，才称得上大，三昧就是大定，也就是永远没有入也没有出。那好了，那三昧，佛经上有所谓的百八三昧……所有的三昧都是一样的，是从哪个方面而入……无诤三昧，这个诤字其实有争论辩论的意思，或者说话会得罪人惹来麻烦。无诤三昧就是他真正达到能够无为而无不为这种境界。所以你念佛念到念佛三昧，你真正达到标准的念佛三昧，境界是和须菩提的无诤三昧是一样的，都是三昧。

……假如我拿出两把铁锤，两把一模一样的铁锤，然后我就问，这两把铁锤用来砸这个砖，你觉得哪把厉害啊？……我拿出两块砖摆在地上，而且告诉你这两块砖是一样的，一样的质量的，然后也拿两把铁锤，我们去五金店买的，一样的，一个牌子，一个样子，没有差别的——你看哪把厉害啊？

……一样啊，那好了，我等一会拿起来，第一把铁锤轻轻地敲一下一块砖，唉，砖没事啊，铁锤这么差劲，然后，我就放下这把，拿第二把，然后就猛地一下对那块砖打下去，那块砖马上碎了，哎呀，这把厉害，嗯是不是，那怎么说呢？同样是无诤三昧，有大愿力和没有大愿力是不一样的，在这一点。另外，这个发愿，永嘉大师在《证道歌》里面告诉我们，一地具足一切地，你就算刚刚证得初地，如果你刹那间发大愿，你甚至马上超越到多少地啊，你知不知道？甚至马上到法云地，是不是啊，你们要知道，同样是无诤三昧，你有发大愿和没有发大愿。
