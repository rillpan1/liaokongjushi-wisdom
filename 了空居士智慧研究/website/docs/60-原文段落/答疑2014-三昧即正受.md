# 答疑2014-三昧即正受

> 来源：[03_答疑专辑2014_佛道](/01-Raw-Sources/03_答疑专辑2014_佛道)
> 切分日期：2026-05-06

**原文：**

师兄问：请问你刚才说的三昧具体是什么？

师父答：噢！三昧也叫做正受（端正的正，接受的受），也就是佛家"四圣谛八正道"里边的正定，也就是说很多人说我要练功了，我要入静了或者说我来入定了，有个"入"。等一下"我收工了，我出定了。"，这个就叫做外道定，就是说我用心去定，也用心去出，引用《六祖坛经》里边有个弟子叫做玄策去拜访一位禅师，就是说他曾经得到五祖的指点修得了正受这个三昧，那个玄策就问他"你在入定的时候是有心入的还是无心入？"，他那个禅师就想了一下说，"我正在入定之时就没有觉得有无之心，没有有心也没有无心，很自然地进去。"这个玄策就说"对了对了，你这个就是对了。这个就是三昧了。"这个三昧是我说的，就是说他这么修就正确了，他就让玄策帮他印证，玄策就说"你还是去曹溪拜见六祖吧，六祖帮你印证那个就不同了。"那个玄策就跟他这么解释。假如是有心入，那一切有情众生都可以入此定，那个就没有什么修不修的问题了，如果是无心入，那一切草木瓦砾（就是石头泥土）都可以合此定，那么我们也不用修了，所以那个禅师就说："我正入定时就不见有无之心。"三昧就是你们每次打坐的时候你们不用特别地排除念头静坐，反而是要将念头捋顺，你们一坐下来，就想一下我心中有什么事情需要我捋顺的我就将它捋顺，如果没有事情捋顺的，你就自然念佛就好了。念着念着就会觉得身体越来越虚无，越来越舒服了，这个就是非有心非无心的自然深入定境，这就是三昧。谢谢大家！
