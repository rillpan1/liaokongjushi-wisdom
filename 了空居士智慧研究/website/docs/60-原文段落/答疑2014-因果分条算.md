# 答疑2014-因果分条算

> 来源：[03_答疑专辑2014_佛道](/01-Raw-Sources/03_答疑专辑2014_佛道)
> 原章节：不守五戒念佛有用吗？
> 切分日期：2026-05-06

---

师兄问：我不守五戒，念佛有用吗？

师父答：有用，因果是一条一条来的。你念佛，你虔诚念佛，你这个就是跟佛结缘，守五戒是使你的心安定，使你不造恶业，使你不增长恶业力。打个比方，你杀、盗、淫、妄你都在犯恶，你一心念佛你跟佛结缘，那如果罪业造太大了，万一以后堕落恶道，一样跟佛有缘，寺庙里很多狗啊、猪啊，人家放生的那些人，就是过去身跟佛结缘的，但是他就是因为他不持戒，从而堕落恶道。因果是分毫不爽的，一条一条来的。谢谢大家！
