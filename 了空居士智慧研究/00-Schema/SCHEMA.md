# SCHEMA.md - 了空居士智慧研究 维护规范

> 本文件是整个知识库的"宪法"，指导 LLM 如何维护这个 wiki。
> 融合两套方法论：
> 1. Andrej Karpathy 的 LLM Wiki 思路（持久化、增量构建、LLM 作为维护者）
> 2. "模型原子→核心心智模型→五层结构"方法（知识蒸馏、结构化组织）

---

## 项目愿景

系统性研究了空居士的教导，构建**可持久化、可查询、可积累**的结构化智慧体系。

**核心理念**：
- 不是每次提问都重新检索碎片 → 构建持久化的结构化知识
- 不是静态的文档集合 → 会生长、自我修正的知识网络
- 不是人来做维护 → LLM 承担所有 bookkeeping 工作
- 不是按章节摘录 → **按"模型原子"提炼原则性语句**

---

## 方法论融合

### 两套方法的结合点

| 维度 | Karpathy LLM Wiki | 模型原子方法 | 融合后 |
|------|-------------------|-------------|--------|
| **知识来源** | Raw Sources | 原始文章 | Raw Sources（不变） |
| **知识提取** | 增量读取+整合 | 提炼"模型原子" | **双重工作流** |
| **知识组织** | Wiki（分类目录） | 七大核心模型 | **五层结构** |
| **维护方式** | LLM 自动维护 | 人工归纳 | LLM + 人类协作 |
| **目标** | 持久化检索 | 系统化理解 | **智慧内化与应用** |

### 融合的核心创新

1. **"蒸馏"比"摘录"更重要**：从原文提炼"模型原子"（指导判断与行动的原则性语句），而非简单复制章节
2. **五层结构是 Wiki 的导航层**：在 Wiki 的分类目录之上，构建"模型→专题→路径→原话→概念"的导航体系
3. **LLM 做"苦力"，人类做"思考"**：LLM 负责提炼、聚类、更新，人类负责指导方向、验证深度

## 四层架构（融合版）

```
01-Raw-Sources/    ← 原始来源层（不可变）
    ↓ 双重提取：分类整理 + 模型原子提炼
02-Wiki/           ← Wiki 层（LLM 维护）
    ↓ 五层导航：模型层 + 专题层 + 路径层 + 原话层 + 概念层
03-Output/         ← 最终产物（用户消费）
    ↓
00-Schema/         ← Schema 层（维护规范）
```

### 各层职责

| 层级 | 路径 | 职责 | 谁维护 |
|------|------|------|--------|
| **Raw Sources** | `01-Raw-Sources/` | 原始文章，事实来源 | 人类放置，LLM 只读 |
| **Wiki** | `02-Wiki/` | 结构化知识 + 五层导航 | LLM + 人类协作 |
| **Output** | `03-Output/` | 最终产物（指南、报告） | LLM 生成，人类阅读 |
| **Schema** | `00-Schema/` | 维护规范、工作流定义 | 人类 + LLM 共同发展 |

## Wiki 五层结构详解

### 第一层：模型层（骨架）⭐

> **核心心智模型的主页面**，是整个知识库的"骨架"。

每个核心模型一个页面，包含：
- **定义**：模型的精确定义
- **核心内涵**：为什么这个模型重要
- **模型原子**：组成这个模型的原则性语句
- **知识库出处**：相关原话链接
- **实践指引**：如何在日常生活中运用

```
02-Wiki/
├── 10-核心模型/              # ★ 第一层：模型层
│   ├── model-整体观.md
│   ├── model-无为.md
│   ├── model-无不为.md
│   ├── model-中道.md
│   ├── model-融通.md
│   ├── model-历境炼心.md
│   ├── model-三贯通验证.md
│   └── 10-核心模型_INDEX.md   # 模型层索引
```

### 第二层：专题层（组合应用）

> **复杂问题分析**，组合多个模型进行剖析。

专题类型：
- **人生困惑**：如何面对焦虑、如何处理情绪、如何做出选择
- **修行情境**：如何入门实修、如何克服懈怠、如何验证境界
- **现代应用**："守中"的现代含义、如何在工作中修行

```
02-Wiki/
├── 20-专题研究/              # ★ 第二层：专题层
│   ├── topic-焦虑.md
│   ├── topic-情绪.md
│   ├── topic-选择.md
│   ├── topic-入门实修.md
│   └── 20-专题研究_INDEX.md
```

### 第三层：路径层（学习地图）

> **学习路线图**，帮助用户按次第深入。

两条路径：
- **认知路径**：整体观（世界观）→ 无为（心态）→ 无不为（方法）→ 中道（验证）
- **问题路径**：如何入门实修？→ 如何处理情绪？→ 如何理解经典？


## 双工作流：摄取 + 提炼

### 工作流 A：摄取（Ingest）

> 当有新文章加入时执行。

1. 阅读原始文章
2. 按分类整理信息（修行方法、经典讲解、处世智慧等）
3. 更新 Wiki 对应页面
4. 更新索引和日志

### 工作流 B：提炼（Extract）⭐

> 这是融合方法的核心创新。

1. **扫描模型原子**
   - 从文章中识别"能够指导判断与行动的原则性语句"
   - 示例原文："不被现象所迷惑，保持最清净的心去看待一切。"
   - 提炼为原子：【离相】【清净心】

2. **聚类到核心模型**
   - 将新提炼的原子归入已有核心模型
   - 如新原子无法归入 → 考虑创建新模型或专题

3. **更新模型页面**
   - 在对应模型的页面中增量添加原子
   - 更新"模型原子"列表
   - 添加原文引用

4. **提炼金句**
   - 识别口语化、直指人心的精彩原话
   - 存入 `40-原话金句/` 对应文件
   - 按模型索引建立链接

## 模型原子提炼指南

### 什么是"模型原子"？

**定义**：能够指导判断与行动的原则性语句，是构建心智模型的最小单元。

**特征**：
- ✅ 是原则，不是描述
- ✅ 可以指导行动或判断
- ✅ 通常简洁有力
- ✅ 有普适性，超越具体情境

### 提炼示例

| 原文 | 提炼的原子 | 归属模型 |
|------|-----------|---------|
| "凡事尽力而为，做人问心无愧。" | 【尽力】【问心无愧】 | 无不为 + 无为 |
| "不被现象所迷惑，保持最清净的心去看待一切。" | 【离相】【清净心】 | 整体观 + 中道 |
| "司空见惯就是平常心。" | 【平常心】【境不转心】 | 中道 + 历境炼心 |
| "烦恼即菩提。" | 【烦恼即菩提】【转境】 | 历境炼心 |
| "做就是了。" | 【行动力】【当下】 | 无不为 |

### 注意事项

- **保留原话**：每个原子都要保留原始出处
- **不过度抽象**：原子要保持可操作性，不要抽象到失去指导意义
- **允许模糊**：部分原子可能归属多个模型，这是正常的

## Lint 检查（定期维护）

### 检查清单

- [ ] **孤立页面**：没有被其他页面链接的页面
- [ ] **原子覆盖度**：每个核心模型的原子是否充足？
- [ ] **专题完整性**：专题是否组合了多个模型？
- [ ] **路径连贯性**：学习路径是否清晰可达？
- [ ] **交叉引用**：相关页面之间是否互相链接？
- [ ] **矛盾检测**：是否有矛盾或待澄清的观点？

### 执行频率

- 每次摄取 5-10 篇新文章后执行一次
- 每月执行一次全面检查

## 命名规范

### 文件命名

- **模型页面**：`model-xxx.md`（如 `model-整体观.md`）
- **专题页面**：`topic-xxx.md`（如 `topic-焦虑.md`）

```markdown

```

使用 `[[wikilink]]` 格式：
```markdown

```

```markdown
> 来源：[[01-Raw-Sources/xxx.md]] | 提炼日期：2026-05-05
```

## 人类与 LLM 的分工

### 人类的工作

- 制定方向（哪些模型最重要？）
- 验证深度（提炼的原子是否准确？）
- 指导整合（如何组合多个模型分析问题？）
- 思考应用（这个智慧如何落地？）

### LLM 的工作

- 扫描原文，提炼模型原子
- 维护 Wiki 页面的结构和内容
- 更新交叉引用和索引
- 执行 lint 检查
- 生成报告和建议
