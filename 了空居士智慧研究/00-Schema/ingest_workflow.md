# ingest_workflow.md - 摄取工作流详细说明

> 本文档是 SCHEMA.md 中"摄取工作流"的详细操作指南。
> 每当有新文章加入 `01-Raw-Sources/` 时，严格按照本流程执行。

---

## 前置检查

1. 确认新文章已放置在 `01-Raw-Sources/` 目录
2. 确认文章格式为 `.md`（Markdown）
3. 确认文章标题清晰可读

---

## 详细步骤

### Step 1：阅读并理解原始文章

**操作**：
- 使用 `Read` 工具读取文章全文
- 理解文章的核心主题（属于哪个分类？）
- 识别关键信息点

**提取要素清单**：
- [ ] 核心观点（central claims）
- [ ] 关键概念（key concepts）→ 可能需要创建概念页面
- [ ] 修行方法（practice methods）→ 归入 `03-修行方法/`
- [ ] 公案案例（cases/stories）→ 归入 `05-公案参究/`
- [ ] 丹道知识（alchemical knowledge）→ 归入 `07-丹道修炼/`
- [ ] 处世智慧（worldly wisdom）→ 归入 `04-处世智慧/`
- [ ] 经典引用（classic citations）→ 归入 `02-经典讲解/`
- [ ] 答疑内容（Q&A）→ 归入 `06-答疑解惑/`

**输出**：
- 在心中形成文章的结构化摘要
- 识别与其他已知概念/页面的潜在联系

---

### Step 2：决策 - 创建新页面 or 更新现有页面？

**判断逻辑**：

```
这个关键信息属于哪个分类？
    └─> 该分类下是否已存在相关页面？
            ├─> 是 → 更新现有页面（增量添加）
            └─> 否 → 创建新页面
```

**示例**：
- 文章讲解了"心若寒冰" → 检查 `01-核心心法/` 是否已有 `xin-ruo-han-bing.md`
  - 有 → 在现有页面中添加新信息
  - 无 → 创建 `xin-ruo-han-bing.md`

---

### Step 3：创建或更新 Wiki 页面

#### 创建新页面模板

```markdown
# 页面标题（中文）

> 创建日期：YYYY-MM-DD
> 最后更新：YYYY-MM-DD

## 概述
简要描述本页面主题。

## 核心内容
详细内容...

## 来源文章
- [文章标题1](原始文章路径) | 摄取日期：YYYY-MM-DD
- [文章标题2](原始文章路径) | 摄取日期：YYYY-MM-DD

## 相关页面
- [[相关页面1]]
- [[相关页面2]]

## 待深入探讨
（留空，后续补充）
```

#### 更新现有页面

**操作原则**：
- 不要删除原有内容
- 在合适位置**增量添加**新信息
- 如果新信息与旧信息矛盾 → 记录到 `contradictions.md`
- 更新页面顶部的"最后更新"日期

**添加新来源的模板**：
```markdown
## 来源文章
- [原有来源](...) | 摄取日期：...
- [新来源标题](新文章路径) | 摄取日期：YYYY-MM-DD  ← 新增
```

---

### Step 4：添加交叉引用

**这是最关键的一步！**

在每个相关页面中：
1. 读取该页面的现有内容
2. 在"相关页面"段落中添加新创建的页面链接
3. 同时，在新创建的页面中，添加回链到相关页面

**示例**：
- 创建了 `xin-ruo-han-bing.md`
- 发现它与 `bu-er-xin-fa.md` 相关
- 操作：
  - 在 `xin-ruo-han-bing.md` 的"相关页面"中添加 `[[bu-er-xin-fa|不二心法]]`
  - 在 `bu-er-xin-fa.md` 的"相关页面"中添加 `[[xin-ruo-han-bing|心若寒冰]]`

---

### Step 5：更新 index.md

**操作**：
1. 读取 `02-Wiki/index.md`
2. 在合适的分类下添加新页面条目
3. 格式：`- [[file-name|显示标题]] - 一句话描述 (来源: X篇文章)`

**示例**：
```markdown
## 核心心法
- [[xin-ruo-han-bing|心若寒冰]] - 不动心的心法 (来源: 3篇文章)
- [[bu-er-xin-fa|不二心法]] - 超越对立的智慧 (来源: 5篇文章)
- [[xin-ruo-han-bing|心若寒冰]] - 不动心的心法 (来源: 3篇文章)  ← 新增
```

---

### Step 6：更新 log.md

**操作**：
1. 读取 `02-Wiki/log.md`
2. 在文件末尾追加新条目

**格式模板**：
```markdown
## [YYYY-MM-DD] ingest | 文章标题

- 创建了 X 个新页面：
  - [[页面1]]
  - [[页面2]]
- 更新了 Y 个现有页面：
  - [[页面3]]（添加了新信息）
- 发现矛盾：
  - （如无矛盾，删除此行）
- 处理人：LLM
```

---

### Step 7：更新交叉引用表（可选，但推荐）

**操作**：
1. 读取 `02-Wiki/99-索引资料/cross-refs.md`
2. 添加新建立的交叉引用关系

**格式**：
```markdown
| 源页面 | 目标页面 | 关系类型 | 建立日期 |
|--------|----------|----------|----------|
| [[xin-ruo-han-bing]] | [[bu-er-xin-fa]] | 相关概念 | 2026-05-05 |
```

---

### Step 8：检查矛盾

**操作**：
1. 回顾新信息与已有内容是否有冲突？
2. 如果有 → 读取 `02-Wiki/99-索引资料/contradictions.md`
3. 追加矛盾记录

**格式**：
```markdown
### [YYYY-MM-DD] 矛盾描述

- **冲突点**：具体描述
- **来源A**：[文章标题](路径) 中的观点
- **来源B**：[文章标题](路径) 中的观点
- **状态**：待澄清 / 已解决（附解决方案）
```

## 质量检查（完成后自查）

- [ ] 所有新创建的页面都有 `[[wikilink]]` 交叉引用
- [ ] `index.md` 已更新
- [ ] `log.md` 已追加条目
- [ ] 来源标注完整（每条信息都有出处）
- [ ] 没有孤立页面（每个页面至少有一个入站链接）
- [ ] 中文标题清晰，英文文件名规范

## 批量摄取策略

如果一次性摄取多篇文章（如初始化时的124篇）：

### 推荐策略
1. **分批处理**：每次处理 5-10 篇
2. **交替进行**：先快速提取，再深入整合
3. **定期 lint**：每处理 20 篇执行一次 lint 检查

### 初始化特别说明
- 第一批：专注于创建核心分类页面（如 `01-核心心法/` 下的主要概念）
- 第二批：填充细节，建立交叉引用
- 第三批：查漏补缺，完善索引

## 常见问题

### Q1：如果一篇文章涉及多个分类怎么办？
**A**：创建多个页面的条目，或在主分类页面中提及其他分类的链接。

### Q2：如果无法判断属于哪个分类怎么办？
**A**：暂时放入 `08-专题研究/`，后续重新评估。

### Q3：如果文章质量很差（乱码、重复）怎么办？
**A**：在 `log.md` 中记录，跳过该文章。

### Q4：交叉引用太多，页面显得杂乱怎么办？
**A**：只保留最相关的 5-10 个链接，其他的通过主题分类间接关联。
