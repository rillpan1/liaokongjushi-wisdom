---

## 核心理念

**"蒸馏"比"摘录"更重要**

- ❌ 摘录：复制章节、整理段落
- ✅ 蒸馏：**提炼能够指导判断与行动的原则性语句**

> 想象一下：原文是一杯混浊的原料酒，"模型原子"是提纯后的精华。

---

## 什么是"模型原子"？

### 定义

**模型原子**是构建心智模型的最小单元，是能够指导判断与行动的原则性语句。

### 特征

| 特征 | 说明 |
|------|------|
| **原则性** | 是原则，不是描述或故事 |
| **可操作性** | 可以指导具体行动或判断 |
| **简洁有力** | 通常简短有力，易于记忆 |
| **普适性** | 超越具体情境，有普遍意义 |

### 示例

| 类型 | 示例 | 是否为原子 |
|------|------|-----------|
| 描述 | "张三打坐时感觉很安静。" | ❌ |
| 故事 | "从前有一个人修行，后来开悟了。" | ❌ |
| 原则 | "静坐时杂念来了，看着它，不跟随。" | ✅ |
| 原则 | "凡事尽力而为，做人问心无愧。" | ✅ |

## 提炼步骤

### Step 1：扫描原文，标记潜在原子

**操作**：
1. 逐段阅读原文
2. 标记那些：
   - 包含判断性语句的段落
   - 给出指导或建议的内容
   - 表达核心观点的金句
   - 可以提炼为原则的表述

**标记格式**：
```markdown
[原子候选] "原文原话"
[原因] 为什么这个值得提炼
```

### Step 2：提炼原子

**操作**：
对每个候选进行提炼：

1. **提取核心原则**：从原文中提取最核心的原则
2. **命名原子**：用 1-2 个词命名这个原子
   - 如："不被现象所迷惑" → 【离相】
   - 如："保持最清净的心" → 【清净心】
3. **判断归属**：这个原子属于哪个核心模型？

**命名规范**：
- 使用 1-4 个汉字
- 优先使用原文中的关键词
- 如无合适词，可自拟（如【平常心】）

### Step 3：验证原子质量

**检查清单**：
- [ ] 这个原子是否足够"原则性"？
- [ ] 这个原子是否可以指导行动或判断？
- [ ] 这个原子是否简洁（便于记忆）？
- [ ] 这个原子是否有普适性？

**如果任何一个答案是否定的**：
- 考虑放弃这个候选
- 或重新提炼到更核心的原则

### Step 4：归入核心模型

**七大和空居士核心模型**：

| 模型 | 核心内涵 | 典型原子 |
|------|---------|---------|
| 整体观 | 万物一体，宇宙统一场 | 【因缘和合】【天人合一】【一体】 |
| 无为 | 不执着，问心无愧 | 【不执着】【顺其自然】【放下】 |
| 无不为 | 尽力而为，实事求是 | 【尽力】【做就是了】【行动】 |
| 中道 | 不落两边，动态平衡 | 【平常心】【中道】【平衡】 |
| 融通 | 师力加持，以众生为师 | 【普贤行】【众生为师】【师承】 |
| 历境炼心 | 烦恼即菩提，境随心转 | 【烦恼即菩提】【转境】【炼心】 |
| 三贯通验证 | 经典互证，逻辑自洽，生活实用 | 【经典】【逻辑】【生活】 |

**如果原子不属于任何已有模型**：
- 暂时放入"待归类"
- 后续评估是否需要创建新模型或专题

### Step 5：更新 Wiki 页面

**操作**：

1. **更新模型页面**：
   ```markdown
   ## 模型原子
   
   - 【离相】- 不被现象所迷惑（来源：金刚经讲解）
   - 【清净心】- 保持最清净的心（来源：金刚经讲解）
   ```

2. **更新原话金句页**：
   ```markdown
   ## 金刚经相关
   
   > "不被现象所迷惑，保持最清净的心去看待一切。"
   > —— [[01-Raw-Sources/金刚经讲解.md]]
   ```

3. **更新索引**：
   - 更新 `10-核心模型_INDEX.md`
   - 更新 `40-原话金句_INDEX.md`

## 提炼示例

### 示例：原文

> "我们修行，不是要压制念头，而是要看着念头来来去去，不跟随它，不抵制它。就像看河水流淌，你站在岸上看着，不跳进去。静坐时杂念来了，看着它，不跟随，不攀缘，它自然就消失了。"

### Step 1：扫描标记

```markdown
[候选1] "看着念头来来去去，不跟随它，不抵制它"
[候选2] "就像看河水流淌，你站在岸上看着，不跳进去"
[候选3] "静坐时杂念来了，看着它，不跟随，不攀缘，它自然就消失了"
```

### Step 2：提炼原子

| 候选 | 提炼的原子 | 命名 |
|------|-----------|------|
| 候选1 | 观察念头而不跟随 | 【观照】 |
| 候选2 | 旁观者视角 | 【旁观者】 |
| 候选3 | 不攀缘，杂念自消 | 【不攀缘】 |

### Step 3：验证

- 【观照】：✅ 原则性、✅ 可操作、✅ 简洁、✅ 普适
- 【旁观者】：✅ 原则性、✅ 可操作、✅ 简洁、✅ 普适
- 【不攀缘】：✅ 原则性、✅ 可操作、✅ 简洁、✅ 普适

### Step 4：归入模型

| 原子 | 归属模型 | 理由 |
|------|---------|------|
| 【观照】 | 修行方法 / 中道 | 观照而不干预，是中道的体现 |
| 【旁观者】 | 中道 / 历境炼心 | 保持距离观察，不被境转 |
| 【不攀缘】 | 无为 | 不执着、不攀缘，是无为的体现 |

### Step 5：更新页面

**model-中道.md** 中添加：
```markdown
## 模型原子

### 观照类
- 【观照】- 看着念头来来去去，不跟随不抵制 | 来源：静坐方法讲解
- 【旁观者】- 如旁观者看河水，不跳入 | 来源：静坐方法讲解
```

**model-无为.md** 中添加：
```markdown
## 模型原子

### 不执着类
- 【不攀缘】- 杂念来了不跟随，自然消失 | 来源：静坐方法讲解
```

## 批量提炼策略

### 初始化阶段（第一批）

1. **先选定 3-5 篇核心文章**（如《金刚经》全32分讲解）
2. **全量提炼**：不遗漏任何潜在原子
3. **建立模型框架**：确保七个核心模型都有足够原子支撑

### 稳定阶段（后续批次）

1. **选择性提炼**：重点关注新概念、新观点
2. **补充完善**：为已有模型添加更多原子
3. **专题驱动**：为准备创建的专题优先提炼相关原子

## 质量标准

### 优秀原子

- 简洁（1-4个字）
- 有力（直指核心）
- 可操作（可以落地）
- 有出处（标注来源）

### 需要避免

- ❌ 过于抽象（如【道】【佛性】等大词，需具体化）
- ❌ 过于具体（如【打坐时腿麻怎么办】，需提炼原则）
- ❌ 互相重复（注意合并相似原子）
- ❌ 没有出处（必须标注来源）

## 常见问题

### Q1：一个段落提炼出多个原子，归属不同模型，正常吗？

**A**：正常。好的原文往往蕴含多个智慧点。归属不同模型说明这个原文有多层含义。

### Q2：提炼的原子太多，会不会碎片化？

**A**：这是好事。原子多才有组合的空间。关键是后续的**聚类和整合**——将相关原子归入核心模型，形成框架。

### Q3：有些原子感觉归属于多个模型，怎么办？

**A**：
- 如果确实如此，在多个模型中都收录
- 使用交叉引用（`[[wikilink]]`）关联
- 这是正常的，说明原子有普适性

### Q4：原文是口语化的，直译感觉不够"高大上"？

**A**：
- ✅ 保留口语化！了空居士的特色就是"口语化、直指人心"
- 口语化更接地气，更有感染力
- 不要为了"高大上"而牺牲原意

## 与摄取工作流的区别

| 维度 | 摄取工作流 | 提炼工作流 |
|------|-----------|-----------|
| **目的** | 整理信息到分类目录 | 提炼"模型原子" |
| **关注点** | 文章写了什么 | 文章想说什么原则 |
| **产出** | 分类页面（修行方法、经典讲解等） | 模型原子 + 模型页面 |
| **深度** | 整理 | 蒸馏 |
| **频率** | 每次新文章都做 | 每次新文章都做 |

**两者并行不悖**：摄取工作流负责"整理"，提炼工作流负责"蒸馏"，共同丰富 Wiki。
