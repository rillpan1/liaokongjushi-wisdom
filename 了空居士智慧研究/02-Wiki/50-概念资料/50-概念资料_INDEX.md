## 初学推荐阅读顺序

第一次接触了空居士的概念体系，建议按以下顺序阅读：

1. **清净心** → 了解修行目标（心是什么状态）
2. **烦恼** → 了解修行的材料（烦恼就是机会）
3. **平常心** → 了解修行的日常状态（平常是道）
4. **无为** → 了解修行的行动原则（做就是了，不妄为）
5. **丹田 + 观照** → 了解基本功（轻轻返观中丹田）

## 传统交叉对照

了空居士的独特贡献在于**融合四家**：

| 概念 | 佛家解读 | 道家解读 | 儒家解读 |
|------|---------|---------|---------|
| 无为 | 应无所住而生其心 | 道法自然，不妄为 | — |
| 中道 | 不执有，不执空 | 守中（看准时机） | 中庸（不偏不倚） |
| 自然 | 法尔如是 | 道法自然 | 天性 |
| 平常心 | 无住生心 | 顺其自然 | 司空见惯 |
| 爱 | 慈悲（同体大悲） | 上善若水 | 仁（爱人如己） |
| 至善 | 涅槃 | 归根 | 至善 |
